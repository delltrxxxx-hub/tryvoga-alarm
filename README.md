# Тривожний Будильник

Android-будильник, який враховує повітряну тривогу в Україні.

- Червона / жовта тривога — окрема гучність і вібрація (або повна тиша) для кожного будильника.
- «Розбудити після відбою»: якщо будильник промовчав через тривогу, він задзвонить після відбою.
- Голосове оголошення: час і яка зараз тривога.
- Статус з точністю до громади, перевірка кожні 15 секунд. Дані безкоштовні, без токена:
  [siren.pp.ua](https://siren.pp.ua) (дані «Повітряна тривога») і публічна стрічка [alerts.in.ua](https://alerts.in.ua).
- Власна векторна карта тривог (межі областей — [geoBoundaries](https://www.geoboundaries.org), CC BY 4.0).
- Таймер, секундомір, світовий час, 4 віджети, дизайн Liquid Glass або Material 3.
- Оновлення прямо в застосунку з GitHub Releases.

## Встановлення

Завантажте APK з останнього [релізу](../../releases/latest) і відкрийте його на телефоні (Android 8.0+).
Далі застосунок сам запропонує оновлення.

> Завжди дотримуйтеся офіційних сигналів оповіщення. Застосунок — допоміжний засіб.
